# iPhone-ის ქვედა მოქმედებების ზოლის დაშორება

თარიღი: 2026-11-11
Branch: `codex/fix-ios-listing-bar-gap-20261111`
საფუძველი: `main`, commit `4654563`.

მომხმარებლის ორი ფოტო აჩვენებს განსხვავებას Safari-ის ქვედა პანელის ხილულ და დამალულ მდგომარეობებს შორის. პრობლემა ეხება ნივთის ფასისა და მიწერის ფიქსირებულ ზოლს.

კოდში ზოლის ქვედა დაშორება იყო `calc(var(--mobile-nav-offset) + env(safe-area-inset-bottom))`. iPhone-ის უსაფრთხო ზონის ზომა ამგვარად გარე ცარიელ სივრცედ რჩებოდა. ნივთის გვერდზე საიტის ქვედა ნავიგაცია ისედაც დამალულია, ამიტომ მისი დაშორება ამ კომპონენტს არ სჭირდება.

შესწორება: ზოლის ფონი მიბმულია `bottom: 0`-ზე; უსაფრთხო ზონის ზომა დაემატა შიდა ქვედა padding-ს. ამით ღილაკები ჟესტების ხაზს არ ეფარება, ხოლო ფონი ქვედა კიდემდე გრძელდება. კომპიუტერის `md:static` და `md:p-0` განლაგება შენარჩუნებულია. მიდგომის საფუძველი: [WebKit — Designing Websites for iPhone X](https://webkit.org/blog/7929/designing-websites-for-iphone-x/).

შემოწმება:

- ნივთის გვერდის, ჩათისა და მობილური ზოლების 37 არსებული ტესტი წარმატებულია.
- შეცვლილი კომპონენტის ESLint წარმატებულია.
- სრული Next.js build და TypeScript წარმატებულია; build შესრულდა Node 24.14.1-ზე. ამ commit-ზე Node 22-ის ცალკე CI ჯერ არ შესრულებულა.
- ლოკალური გვერდი აბრუნებს HTTP 200-ს და განახლებული CSS კლასები პასუხშია.
- ბრაუზერში 390×844, 390×720 და 320×740 ზომებზე ზოლის ფონის ქვედა კიდესა და viewport-ის ქვედა კიდეს შორის გაზომილი დაშორება იყო 0px; გადახვევის შემდეგაც 0px დარჩა. 320px-ზე ღილაკი ეკრანის სიგანეს არ გასცდენია.
- 1440px კომპიუტერის ზომაზე დადასტურდა `position: static` და `padding-bottom: 0px`.
- ბრაუზერის ამ შემოწმებაში უსაფრთხო ზონის რეალური inset იყო 0; iPhone-ის 34px inset და Safari-ის საკუთარი toolbar კომპიუტერულ შემოწმებას არ გაუმეორებია. ეს შეზღუდვა არ უნდა ჩაითვალოს ფიზიკური iPhone-ის შემოწმებად.

რეალურ iPhone-ზე Safari-ის პანელის ჩაკეცვა/გაშლა ცალკე გადასამოწმებელია. კომპიუტერში მობილური ზომის შემოწმება ამ ქცევის რეალურ მოწყობილობაზე დადასტურება არ არის.

Production-ზე ცვლილება არ გამოქვეყნებულა. დაბრუნება შესაძლებელია ამ შესწორების ცალკე commit-ის `git revert`-ით.
